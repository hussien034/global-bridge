# Global Bridge 🇪🇬 🌍
**منصة التوظيف التقني الدولي للكوادر والمواهب المصرية**

منصة توظيف متكاملة ومصممة بأحدث معايير الويب والهوية المصرية المعاصرة، تربط الشركات التكنولوجية العالمية في أوروبا وأمريكا الشمالية بنخبة مهندسي البرمجيات في مصر للعمل عن بُعد برواتب بالعملات الأجنبية.

---

## 🧭 بيانات حسابات العرض للتطوير المحلي فقط

هذه حسابات اختبار محلية. سجّل الدخول يدوياً من صفحة `/login` باستخدام البيانات التالية بعد تشغيل `npm run db:seed`. بيانات الدخول لا تعمل في بيئة الإنتاج:

| الدور (Role) | البريد الإلكتروني | كلمة المرور | الصلاحيات ولوحة التحكم |
| :--- | :--- | :--- | :--- |
| **🏢 شركة شريكة (Company)** | `demo-company@globalbridge.dev` | `demo-company` | إدارة وظائف Northstar Labs، نظام ATS، فرز المتقدمين، تدوين الملاحظات |
| **👑 مدير المنصة (Admin)** | `demo-admin@globalbridge.dev` | `demo-admin` | إشراف كامل على كل الشركات، الوظائف، المتقدمين، وسجل تدقيق الأنشطة |
| **👤 مرشح تقني (Candidate)** | `demo-candidate@globalbridge.dev` | `demo-candidate` | تصفح الوظائف، التقديم المباشر المجاني، واستكشاف المسارات التدريبية |

## 🚀 التشغيل السريع (Quick Start)

يتطلب التشغيل Node.js 20.12 أو أحدث.

### 1. تثبيت الحزم (Installation)
```bash
npm install
```

### 2. قاعدة البيانات وتعبئة البيانات التجريبية (SQLite + Drizzle)
```bash
# تطبيق الـ Schema مباشرة
npm run db:push

# إعادة تعبئة البيانات التجريبية (شركات، وظائف، متقدمين، فعاليات)
npm run db:seed
```
> تحذير: `db:seed` يمسح البيانات الحالية ويعيد إنشاء بيانات العرض التجريبية. لا تستخدمه على قاعدة بيانات تحتوي بيانات تريد الاحتفاظ بها.

### الحسابات والتسجيل
- من `/login` يمكن للمرشح إنشاء حساب فوراً، ويمكن للشركات إرسال طلب شراكة ولمستخدمي الإدارة طلب صلاحية للمراجعة. طلبا الشركة وAdmin يظهران في لوحة Admin تحت "طلبات التسجيل والصلاحيات"، ولا ينشئان حساباً أو يمنحان صلاحيات تلقائياً. تفعيل حساب الشركة يتم بعد المراجعة من إدارة الشركات؛ إنشاء Admin يظل إجراءً مقيداً بإعداد الحساب الآمن.
- لا يوجد تسجيل عام للمديرين. أنشئ المدير الأول عبر `ADMIN_EMAIL` و`ADMIN_PASSWORD` في `.env`؛ يجب أن تكون كلمة المرور 12 حرفاً على الأقل. يُنشأ الحساب مرة واحدة عند بدء الخادم، ولا تُستبدل كلمة مروره عند إعادة التشغيل.
- طلب الشركة من صفحة `/companies` لا ينشئ حساباً تلقائياً. بعد مراجعة الطلب، ينشئ المدير الشركة وحساب مسؤولها من لوحة الإدارة ويرسل بيانات الدخول بطريقة آمنة.
- حساب Northstar Labs التجريبي متاح للتطوير المحلي باستخدام بيانات الحساب أعلاه؛ صفحة الدخول لا تعرض بطاقات الدخول التجريبي.
- يمكن للمتقدمين إرفاق السيرة الذاتية اختيارياً كملف PDF بحجم أقصى 5 ميجابايت. تُحفظ الملفات خارج مجلد الملفات العامة، ولا يمكن تنزيلها إلا من حساب الشركة المرتبطة بالوظيفة أو حساب المدير. يحدد `UPLOAD_DIR` مجلد التخزين؛ أضف هذا المجلد إلى خطة النسخ الاحتياطي الآمن للبيانات.

### 3. تشغيل بيئة التطوير المباشرة (Dev Server)
```bash
# انسخ .env.example إلى .env وأضف بيانات المدير الأولية (كلمة مرور من 12 حرفاً على الأقل)
npm run dev
```
- المنصة الرئيسية: [http://localhost:3000](http://localhost:3000)
- فحص صحة الخادم: [http://localhost:3000/api/health](http://localhost:3000/api/health)

### 4. فحص الأنواع الصارم (TypeScript Check)
```bash
npm run check
```

### 5. البناء الكامل للإنتاج (Full Production Build)
```bash
npm run build
```

## 🗺️ خريطة المسارات المعتمدة (`manus-routes.json`)

| `/jobs` | استعراض والبحث في الوظائف المتاحة | Public |
| `/jobs/:id` | تفاصيل الوظيفة والشروط ونطاق الراتب | Public |
| `/jobs/:id/apply` | نموذج التقديم المباشر المجاني | Public |

| `/training/:id` | تفاصيل المسار التدريبي | Public |
| `/companies` | صفحة الشركات وحلول استقطاب المواهب وطلب الشراكة | Public |
| `/about` | عن المنصة، رؤيتنا، وسياسة حماية البيانات | Public |
| `/login` | تسجيل الدخول، تسجيل المرشحين، وطلبات الشركة والإدارة | Public / Auth |
| `/company/dashboard` | لوحة تحكم الشركة ومؤشرات التوظيف | Company (Protected) |
| `/company/jobs` | إدارة وظائف الشركة (نشر، تعديل، إيقاف، وإغلاق) | Company (Protected) |
| `/company/jobs/new` | إنشاء ونشر وظيفة شاغرة جديدة | Company (Protected) |
| `/company/jobs/:id/edit`| تعديل بيانات ونطاق راتب وحالة الوظيفة | Company (Protected) |
| `/company/applicants` | نظام إدارة ومتابعة المتقدمين (ATS) | Company (Protected) |
| `/company/applicants/:id`| ملف المرشح الكامل، تحديث المرحلة، وتدوين الملاحظات | Company (Protected) |
| `/admin` | لوحة الإدارة المركزية الشاملة ومؤشرات المنصة | Admin (Protected) |
| `/admin/companies` | إدارة واعتماد الشركات والشركاء الدوليين | Admin (Protected) |
| `/admin/jobs` | مراقبة كافة الوظائف المنشورة عبر مختلف الشركات | Admin (Protected) |
| `/admin/applicants` | السجل العام لكافة طلبات التقديم في النظام | Admin (Protected) |
| `/admin/training` | إدارة مسارات التدريب الاختيارية | Admin (Protected) |
| `/admin/activity` | سجل عمليات وتغييرات المنصة (Audit Log) | Admin (Protected) |

## ⚖️ معايير الشفافية والنزاهة
1. **التقديم مجاني 100%:** لا يتم فرض أي رسوم على المرشحين المصريين.
2. **التدريبات اختيارية بالكامل:** البرامج التدريبية خدمات إثرائية منفصلة ولا تُشترط للتقديم ولا تضمن التوظيف.
3. **تمييز بيانات العرض:** الشركات والوظائف التجريبية موسومة بوضوح كـ `Demo Partner`.

## 🌐 لغات الواجهة
- ملفات النصوص الثابتة: `client/src/i18n/ar.json` و`client/src/i18n/en.json`.
- استخدم `useTranslation()` من `client/src/i18n` داخل مكونات الواجهة، وأضف كل مفتاح جديد إلى الملفين مع الحفاظ على البنية نفسها.
- يضبط التطبيق لغة الصفحة واتجاهها تلقائياً (`ar` من اليمين إلى اليسار، و`en` من اليسار إلى اليمين)، ويحفظ اختيار المستخدم في المتصفح.
- محتوى الوظائف والشركات والبرامج الذي يدخله المستخدم يُعرض بلغته الأصلية؛ ملفات الترجمة مخصصة لنصوص الواجهة، ولا تُترجم بيانات المستخدم تلقائياً.
